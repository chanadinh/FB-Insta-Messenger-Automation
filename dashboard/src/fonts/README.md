The dashboard serves these unmodified WOFF2 subsets locally, including Vietnamese,
Latin, and Latin Extended. There are no runtime Google Fonts requests.

- Be Vietnam Pro: normal weights 400, 500, 600, 700.
  Source: https://github.com/bettergui/BeVietnamPro
  License: ../../public/fonts/bevietnampro-OFL.txt
- Playfair Display: normal and italic variable weights 400–900.
  Source: https://github.com/google/fonts/tree/main/ofl/playfairdisplay
  License: ../../public/fonts/playfairdisplay-OFL.txt

Downloaded through the Google Fonts CSS API. The original font-family names,
Unicode ranges, and licenses are preserved in fonts.css and public/fonts.
